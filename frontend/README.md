# PDF RAG Frontend

现代化的法律法规智能问答前端界面，基于 Next.js 15 和现代 UI 设计。

## ✨ 特性

- 🚀 **现代技术栈**: Next.js 15 + TypeScript + Tailwind CSS
- 🎨 **精美UI设计**: 响应式布局，支持浅色/深色主题
- 💬 **智能聊天**: 实时问答，思考过程可视化
- 📄 **文档查看**: 双模式显示，Markdown 预览与源码切换
- 🔍 **智能搜索**: 文档内搜索，智能高亮显示
- 📱 **移动适配**: 完美的移动端响应式体验
- 🎯 **用户体验**: 平滑动画，现代化交互设计

## 🚀 快速开始

### 环境要求
- Node.js 18+
- npm 或 yarn

### 安装启动
```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 构建生产版本
npm run build
npm start
```

访问 [http://localhost:3000](http://localhost:3000) 查看应用

### 环境配置
创建 `.env.local` 文件：
```env
NEXT_PUBLIC_API_URL=http://localhost:8000
```

## 🏗️ 项目结构

```
src/
├── app/                 # Next.js App Router
│   ├── globals.css     # 全局样式和主题变量
│   ├── layout.tsx      # 根布局和主题提供者
│   └── page.tsx        # 主页面
├── components/         # React 组件
│   ├── ui/            # 基础 UI 组件 (Button, Input, Card)
│   ├── chat/          # 聊天相关组件
│   │   └── ChatInterface.tsx    # 核心聊天界面
│   └── document/      # 文档相关组件
│       └── DocumentViewer.tsx   # 文档查看器
├── lib/               # 工具库
│   ├── api.ts         # API 客户端
│   ├── theme.ts       # 主题管理
│   ├── utils.ts       # 工具函数
│   └── rehypeHighlightSearch.ts # 搜索高亮插件
└── styles/            # 样式文件
```

## 🎨 核心功能

### 聊天界面
- **实时对话**: 与后端 AI 的实时问答交互
- **消息历史**: 完整的对话历史记录
- **思考过程**: AI 分析过程的可视化展示
- **源文档引用**: 显示答案来源和相似度评分
- **文档操作**: 查看和下载引用文档

### 文档查看器
- **双模式显示**: Markdown 预览模式和源码模式
- **智能高亮**: 基于 rehype 插件的搜索高亮
- **片段定位**: 精确的文档片段定位和展示
- **字体调节**: 用户可调节的字体大小
- **文档搜索**: 实时文档内容搜索

### 主题系统
- **双主题**: 浅色和深色主题切换
- **智能适配**: 所有组件的主题自适应
- **用户偏好**: 本地存储用户主题选择
- **平滑切换**: 无刷新的主题切换体验

### UI 优化
- **现代设计**: 毛玻璃效果，大圆角，渐变色
- **交互反馈**: 平滑动画和悬停效果
- **响应式**: 完美适配各种屏幕尺寸
- **无障碍**: 良好的键盘导航和屏幕阅读器支持

## 🔧 技术栈

### 前端框架
